# أساطير اليوتيوب: حرب الخوارزمية المظلمة 🎮
### Arab Gamers: The 20-Stage Pixel Campaign (Enhanced Edition)

![Arab Gamers: 20-Stage Campaign](assets/favicon.svg)

> لعبة أكشن ومنصات ريترو بكسل آرت (2D Pixel-Art Action/Platformer) متكاملة من **20 مرحلة ملحمية**، تضم أسلحة فريدة لـ 5 من أشهر صناع محتوى الجيمنج العرب، حوارات قصصية مشوقة (Typewriter RTL Cutscenes)، محرك مهام وشرط جمع المشتركين (Subscriber Quota)، نظام حفظ المراحل المقفلة (LocalStorage Progression)، ومؤثرات صوتية ميكانيكية نقية (SFX Only - بدون موسيقى).

## 🌟 قصة اللعبة والشخصيات (Story & Heroes)
شنت فيروسات **الخوارزمية المظلمة (Error 404)** هجوماً غادراً على منصة اليوتيوب واختطفت ملايين المتابعين والمشتركين!
يتحد أساطير الجيمنج العرب (بندريتا، ملزلز، أوسمز، أبو عابد، أوبلز) في رحلة من 20 مرحلة عبر مدينة الستريم، غابة الرعب، سماء السيرفرات السحابية، مناجم الريدستون، واللوحة الأم لتحرير المشتركين وكسر كود الخوارزمية المظلمة.

## 🔒 نظام حفظ وفتح المراحل (Progression & Quotas)
- **المراحل مقفلة بالتتابع 🔒:** تبدأ بالمرحلة 1، وكل مرحلة تفتح بعد إنهاء المرحلة السابقة وتُحفظ في `localStorage`.
- **شرط جمع المشتركين (Subscriber Quota):** في كل مرحلة، يجب عليك جمع عدد المشتركين المطلوب (مثلاً 50,000 إلى 250,000 مشترك) بالإضافة لإنجاز المهمة المطلوبة لفتح بوابة العبور!
- **تقييم النجوم ⭐:** يتم منح النجوم بناءً على الأداء والنقاط لكل مرحلة.
- **حوارات منتصف المرحلة (Mid-Level Cutscenes):** تظهر حوارات تفاعلية مشوقة عند الوصول إلى معالم رئيسية داخل المرحلة.

## 🎵 سياسة الصوتيات (SFX Only Policy)
- **بدون أي موسيقى أو نغمات (Zero BGM / Zero Melodies):** اللعبة تعتمد كلياً على **مؤثرات صوتية ميكانيكية وإلكترونية 8-bit** فقط (قفز، ضربات الأسلحة، جمع العناصر، أصوات الحوارات، والانفجارات).

## 🕹️ أزرار التحكم (Controls)

### لوحة المفاتيح (Desktop Keyboard)
- **الحركة (Movement):** `A` / `D` أو الأسهم `◄` `►`
- **القفز (Jump):** `W` / `Space` (يدعم القفز الثلاثي Triple Jump)
- **وميض السرعة (Flash Dash):** `Shift`
- **السلاح الرئيسي (Attack):** `J` أو `Z`
- **المهارة الخارقة (Ultimate):** `K` أو `L` أو `X`
- **تبديل البطل (Switch Hero):** الأرقام `1` - `5`
- **حوار القصة (Dialogue Next):** `Space` أو `Enter`
- **إيقاف مؤقت (Pause):** `P` أو `Esc`

### شاشات اللمس والهواتف (Mobile Touch Controls)
- أزرار **D-Pad** للتنقل يميناً ويساراً.
- زر **DASH** للاندفاع النفاث.
- زر **JUMP** للقفز والقفز الثلاثي.
- زر **ATK** لشن هجمات الأسلحة الفريدة.
- زر **ULT** للمهارات الخارقة.
- زر **بطل** للتبديل السريع بين الشخصيات.
