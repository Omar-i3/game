# Arab Gamers: Pixel Legends | أساطير البكسل 🎮

![Arab Gamers Pixel Legends](assets/favicon.svg)

> لعبة أكشن ومنصات ريترو بكسل آرت (2D Pixel-Art Action/Platformer) متكاملة، مستوحاة من أشهر صُنّاع محتوى الجيمنج في العالم العربي في مواجهة الزعيم الشرير "الباند" (The Ban / Copyright Strike Boss).

---

## 🌟 قصة اللعبة (Lore)
في عالم **"يوتيوب سيتي" (YouTube Neon City)** الرقمي، ظهر كيان شرير مجهول يُدعى **"زعيم الباند" (The Ban Boss)** مسلحاً بمطارق حقوق النشر والإنذارات البرمجية، محاولاً حظر قنوات الجيمنج ومسح ذكريات المتابعين! 
يتحد 5 من أساطير اليوتيوب العرب في ملحمة بكسل بطولية لاستعادة المشتركين وتحرير المنصة!

## 🗺️ المراحل والزعماء (Levels & Bosses)
1. **المرحلة 1: يوتيوب سيتي (YouTube Neon City):** أسطح ناطحات السحاب النيونية، تجنب روبوتات القلتش وطائرات الديسلايك، وجمع المشتركين ولايكات الطاقة.
2. **المرحلة 2: عالم الرعب والبلوكات (Horror & Blocks Realm):** منصات متحركة، كهوف النذر، فخاخ الشوك، ووحوش الأشباح وبلوكات TNT.
3. **المرحلة 3: قاعة الزعيم - الباند (The Ban Boss Arena):** معركة حاسمة متعددة الأطوار ضد زعيم الباند مع دروع طاقة، مطارق السترايك، وموجات الرصاص الحلزونية.

## 🕹️ أزرار التحكم (Controls)

### لوحة المفاتيح (Desktop Keyboard)
- **الحركة (Movement):** `A` / `D` أو الأسهم `◄` `►`
- **القفز (Jump):** `W` / `Space` / `K` أو السهم `▲`
- **الهجوم العادي (Attack):** `J` أو `Z`
- **المهارة الخارقة (Ultimate):** `L` أو `X` (عند امتلاء شريط الطاقة 100%)
- **تبديل البطل (Switch Hero):** الأرقام `1` - `5`
- **إيقاف مؤقت (Pause):** `P` أو `Esc`

### شاشات اللمس والهواتف (Mobile Touch Controls)
- أزرار **D-Pad** للتنقل يميناً ويساراً.
- زر **JUMP** للقفز والقفز المزدوج.
- زر **ATK** لشن الهجمات.
- زر **ULT** لإطلاق المهارات الخاصة.
- زر **بطل** للتبديل السريع بين الشخصيات الخمس.

## 💻 البنية البرمجية والتقنيات (Architecture)
- **HTML5 Canvas 2D:** محرك ألعاب ريترو عالي الأداء بسرعة 60 إطار بالثانية مع معالجة بكسل نقية (`crisp-edges`).
- **Web Audio API:** توليد مؤثرات صوتية ريترو 8-bit وموسيقى Chiptune تفاعلية مخصصة لكل مرحلة برمجياً بدون ملفات صوت خارجية ثقيلة.
- **Particle Physics Engine:** نظام جزيئات متقدم للمؤثرات البصرية والانفجارات وموجات الصدمة وألعاب الاحتفال النارية.
- **Vanilla JavaScript (ES6+):** هيكلية برمجية معيارية ونظيفة بدون أي مكتبات خارجية.

## 🚀 تشغيل اللعبة ونشرها (Run & Deploy)

### التشغيل المحلي (Local Play):
افتح ملف `index.html` في أي متصفح حديث مباشرة، أو شغل خادم محلي خفيف:
```bash
npx serve .
# أو
python -m http.server 8080
```

### النشر على GitHub Pages:
1. ادخل إلى إعدادات المستودع على GitHub: `Settings > Pages`.
2. اختر المصدر: `Deploy from a branch` وحدد الفرع `main` والمجلد `/ (root)`.
3. احفظ الإعدادات وستكون اللعبة متاحة للعب مجاناً عبر الرابط المباشر!
