# أساطير اليوتيوب: حرب الخوارزمية المظلمة 🎮
### Arab Gamers: The 20-Stage Pixel Campaign

![Arab Gamers: 20-Stage Campaign](assets/favicon.svg)

> لعبة أكشن ومنصات ريترو بكسل آرت (2D Pixel-Art Action/Platformer) متكاملة من **20 مرحلة ملحمية**، تضم أسلحة فريدة لـ 5 من أشهر صناع محتوى الجيمنج العرب، حوارات قصصية مشوقة (Typewriter RTL Cutscenes)، ومحرك مهام ديناميكي (Quests & Objectives) في مواجهة كيان الخوارزمية المظلمة (Error 404).

---

## 🌟 قصة الحملة (The Campaign Story)
استيقظ **بندريتا** على إنذار طارئ بفقدان ملايين المشتركين واختراق فيروسات الخوارزمية المظلمة لمدينة الستريم الرقمية!
ينطلق بندريتا في سباق ناري لإنقاذ أفران التميس وفتح خط الاتصال مع **ملزلز** في غابة الرعب، ومنها إلى سماء السيرفرات السحابية مع **أوسمز**، ثم إلى مناجم الريدستون مع **أبو عابد**، واختراق اللوحة الأم مع **أوبلز** وصولاً للحصن الأخير في مواجهة **الخوارزمية المظلمة (Error 404)**!

## 🕹️ أزرار التحكم (Controls)

### لوحة المفاتيح (Desktop Keyboard)
- **الحركة (Movement):** `A` / `D` أو الأسهم `◄` `►`
- **القفز (Jump):** `W` / `Space` / `K` (يدعم القفز الثلاثي Triple Jump)
- **وميض السرعة (Flash Dash):** `Shift`
- **السلاح الرئيسي (Attack):** `J` أو `Z`
- **المهارة الخارقة (Ultimate):** `L` أو `X`
- **تبديل البطل (Switch Hero):** الأرقام `1` - `5`
- **حوار القصة (Dialogue Next):** `Space` أو `Enter`
- **إيقاف مؤقت (Pause):** `P` أو `Esc`

### شاشات اللمس والهواتف (Mobile Touch Controls)
- أزرار **D-Pad** للتنقل يميناً ويساراً.
- زر **DASH** للاندفاع النفاث.
- زر **JUMP** للقفز والقفز الثلاثي.
- زر **ATK** لشن هجمات الأسلحة الفريدة.
- زر **ULT** للمهارات الخارقة.
- زر **بطل** للتبديل السريع بين الشخصيات.

## 🚀 التشغيل والنشر (Run & Deploy)

### التشغيل المحلي:
افتح `index.html` في أي متصفح مباشرة، أو عبر خادم محلي:
```bash
python -m http.server 8080
```

### التفعيل على GitHub Pages:
1. اذهب إلى **Settings > Pages** في مستودع GitHub.
2. اختر الفرع `main` والمجلد `/ (root)`.
3. اضغط **Save** لتصبح اللعبة متاحة للعب مجاناً حول العالم!
